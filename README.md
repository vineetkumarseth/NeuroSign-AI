# 🤟 NeuroSign AI

> Real-Time Indian Sign Language → Text & Speech | Built for 6.3M+ Indians

## 🎯 What It Does
Converts Indian Sign Language gestures into text and spoken words in real time — 
using just a smartphone camera. No app. No special hardware. Completely free.

## ✨ Features
- ⚡ Real-time gesture recognition (<200ms latency)
- 🔊 Voice output in Hindi & English
- 📱 Works on any phone browser
- 📴 Offline mode supported
- 🔤 Word builder — spell full words with signs
- 💯 100% free forever

## 🛠️ Tech Stack
- TensorFlow.js — AI model inference in browser
- Google Teachable Machine — custom ISL model
- Web Speech API — voice output
- HTML + CSS + JavaScript — zero frameworks
